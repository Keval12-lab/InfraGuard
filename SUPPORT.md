## Support Channels

### 1. GitHub Issues (Bug Reports & Feature Requests)

If you encounter a bug or have a suggestion, please open a GitHub Issue.

- Check if the issue is already documented before raising a duplicate.
- Provide a clear description, system environment specs, logs, and a step-by-step reproduction path.

### 2. General Questions

For configuration questions or general discussions, please check our Discussions board or reach out to the project maintainers.
