# UI Guidelines

InfraGuard uses Material UI for all interface elements.

## Application Shell

- Use the shared sidebar and topbar for all main pages.
- Keep spacing consistent with the existing shell layout.
- Use a clean, professional enterprise style.
- Prefer calm surfaces, clear hierarchy, and readable operational layouts.
- Keep cards at 8px border radius or less.
- Avoid introducing alternate UI libraries or unrelated visual styles.

## Current Pages

The routed pages are intentionally empty placeholders for future milestones:

- Dashboard
- Assets
- Network
- Reports
- Settings

No widgets, charts, tables, forms, or product workflows should be added until their milestone is approved.
