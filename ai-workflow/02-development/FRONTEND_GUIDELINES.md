# Frontend Style & Engineering Guidelines

Design rules to maintain the Premium, Minimal, and Fast UI:

1. **Aesthetic Consistency**: Adhere strictly to Outfit/Inter fonts, custom gradients, dark mode panel backdrops (`#0B0F19`), and HSL color metrics.
2. **Tabbed Information Architecture**: Keep configuration dialogues clean by grouping items under descriptive tab interfaces.
3. **Responsive Grids**: Design with flexbox/grid layout systems. Elements must collapse or resize seamlessly on mobile viewports.
4. **Interactive Feedback**: Always provide clear loading spinners (`CircularProgress` or `Skeleton` panels) during asynchronous API request times.
