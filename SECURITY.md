# Security Policy

## Supported Versions

Only the latest stable version of InfraGuard is supported for security patches.

| Version  | Supported |
| :------- | :-------- |
| v1.0.x   | Yes       |
| < v1.0.0 | No        |

## Reporting a Vulnerability

We take the security of InfraGuard seriously. If you find a security vulnerability, please do NOT open a public GitHub issue. Instead, report it privately to our security coordination team.

Please include:

- A description of the vulnerability.
- Steps to reproduce (a proof-of-concept script if possible).
- Any potential impact or threat assessment.

We aim to respond to security reports within 48 hours and provide a patch/advise mitigation steps within 14 days of confirmation.
